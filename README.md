# Madeira AltStore / SideStore source

Auto-updating source for [camhoc/Madeira](https://github.com/camhoc/Madeira) builds. Checks source every hour.

# How to use:

Copy Source URL into AltStore/SideStore/LiveContainer:

```
https://<your-username>.github.io/<this-repo>/source.json
```

Or open the page and press the button on the site.
